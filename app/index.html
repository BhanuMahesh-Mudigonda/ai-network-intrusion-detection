SECTION 1

THE PROBLEM

Why manual traffic inspection is impossible in modern networks

"Network environments generate large numbers of traffic flows. Among normal traffic, some flows may represent malicious activities such as DDoS or PortScan attacks. Manually identifying every flow is difficult."

QUESTION:

"Which traffic flow is suspicious?"

THE SOLUTION: Machine Learning can learn patterns from previously labelled network traffic and automatically classify new traffic flows.

OUR SOLUTION & HOW PREDICTION WORKS

The 5-step classification pipeline

REAL DATASET ROW One network-flow record from CIC-IDS2017
FEATURES Traffic measurements extracted from record
PREPROCESSING Transforms values into model format
XGBOOST MODEL Trained on labelled traffic patterns
PREDICTION Classifies traffic as BENIGN or attack

SECTION 4

HOW THE MODEL LEARNS

Training, preprocessing, and model persistence

01

80/20 STRATIFIED SPLIT

80% training set (2,017,889 flows) / 20% test set (504,473 flows) to prevent data leakage.

02

DATA PREPROCESSING

Convert infinite values, impute column medians, and remove duplicate records.

03

STANDARD SCALING

Scale all 78 numerical features using StandardScaler trained exclusively on training split.

04

XGBOOST ALGORITHM

Train Gradient Boosted Decision Trees to learn complex decision boundaries between BENIGN and attack flows.

05

MODEL EVALUATION

Achieved 99.89% Test Accuracy and 80.38% Minority Recall on unseen test data.

06

FASTAPI SERVICE

Saved model bundle (`best_comparison_model.pkl`) loaded into memory once at API startup.
