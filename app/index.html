SECTION 7

WHAT DOES THE RESULT MEAN?

Understanding the attack classes supported by our trained model

BENIGN

Normal, safe network traffic flow. No security concern detected.

DDoS

Traffic associated with a distributed denial-of-service attack attempting to exhaust server resources.

PortScan

Traffic associated with scanning network ports/services to find open entry points.

Bot

Traffic generated by compromised devices controlled remotely as part of a botnet.

Infiltration

Traffic resulting from internal network breach or unauthorized access attempt.

Web Attack

Traffic targeting web application vulnerabilities such as SQL Injection, XSS, or Brute Force.

Brute Force

Traffic associated with automated password-guessing attacks against network authentication.

Heartbleed

Traffic exploiting the OpenSSL Heartbleed vulnerability to extract server memory.
